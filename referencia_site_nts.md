# Referência de anúncios do site NTS Bike Run

## Objetivo

Definir um padrão de anúncio para bikes à venda no site, separando claramente:

- bloco de imagens
- bloco de texto
- ficha técnica obrigatória
- botão de contato via WhatsApp

Este arquivo serve como referência antes de alterar o site.

## Diretriz principal

Os anúncios devem ter a imagem separada do texto.

Se faltar qualquer informação da bike, não inventar.

Antes de editar ou publicar um anúncio com dados incompletos, pedir a informação faltante primeiro.

Estrutura recomendada:

1. Galeria com 3 a 4 fotos
2. Título e resumo comercial
3. Ficha técnica da bike
4. Faixa de altura ideal
5. Botão de WhatsApp

## Padrão visual recomendado

### Bloco de imagens

- Usar 1 imagem principal em destaque
- Exibir 2 ou 3 miniaturas abaixo ou ao lado
- A primeira imagem deve mostrar a bike inteira
- As demais devem destacar detalhes importantes
- Manter fundo limpo e consistente sempre que possível

### Bloco de texto

- Nome da bike em destaque
- Badges curtos com 3 informações técnicas principais
- Linha curta de apresentação
- Lista objetiva com especificações
- Informação de altura ideal para ajudar na decisão
- Informação fixa de ajuste fino, indicando que permite ajuste para outras alturas
- CTA direto para WhatsApp

### Padrão dos badges

Os badges do topo do anúncio devem ser fixos e escolhidos manualmente para cada bike.

Prioridade recomendada:

1. Tamanho do aro
2. Tamanho do quadro
3. Grupo ou transmissão

Exemplo:

- `Aro 29`
- `Quadro 15`
- `Deore XT 1x10v`

### Ordem ideal das fotos

1. Foto da bike inteira
2. Foto de detalhe do quadro/cockpit
3. Foto do câmbio e transmissão
4. Foto extra opcional de roda, freio, suspensão ou outro detalhe

## Recomendação para o site

Para não misturar arte com conteúdo:

- manter as fotos como fotos, sem texto embutido
- colocar todas as informações no bloco de texto do site
- usar sempre a mesma estrutura para futuros anúncios

## Evolução futura recomendada

Quando houver mais anúncios:

- manter um cadastro por bike
- guardar nome, fotos, especificações e mensagem de WhatsApp em uma estrutura única
- repetir o mesmo layout no site para todas as bikes

## Regra de ordenação dos anúncios

- Anúncios com destaque devem ficar fixos no topo
- Os demais anúncios devem aparecer em ordem aleatória a cada abertura da página
- Para controlar isso no cadastro, cada bike pode ter um marcador de destaque
- Se a bike estiver marcada como destaque, ela não entra na rotação aleatória
